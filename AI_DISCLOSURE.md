# AI assistance and responsibility

This implementation was developed with substantial assistance from OpenAI Codex/ChatGPT: code drafting, refactoring, tests, source-evidence processing, troubleshooting, reproducibility packaging and document drafting. It must not be described as entirely handwritten student code. Pre-existing file-level authorship has not been independently reconstructed. The student remains responsible for understanding and explaining every submitted component and verifying the actual experiments.

The original eight-query Pilot was an AI-assisted convenience design with prior example exposure, not independently authored held-out queries. The latest original action log has369 UI-origin judgments and23 user-requested AI-assisted corrections. The original action history is preserved locally. These corrections must be distinguished from original human opinions when computing supplemental agreement.

The later12-query submission reused eight teaching examples from this conversation. It is retained as AI-assisted development material, not independent query authorship. One copied name was explicitly fictional; soft/hard ambiguity also remains in that draft. The file is not a validated test set.

The second-rater task is80 fixed sampled pairs, ten per original query, collected after the original result publication. The interface does not display the first person's grades or model rankings, but this does not prove that the rater has never seen results elsewhere. Actual judgments were supplied through the participant UI; all80 are handled (78 numeric,2 unknown). Kappa is calculated from the saved actual ratings, not generated to fill missing observations. Final adjudication labels remain blank; no confidence interval or consensus has been fabricated.

Synthetic test records, synthetic grades and tiny random-model numerical checks are used only for software verification. They are not evidence of real places or model effectiveness. Summaries distinguish previous successful function checks from subsequent guard-stopped attempts.
